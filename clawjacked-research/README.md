# ClawJacked Research

Technical analysis and proof-of-concept documentation for security findings related to OpenClaw.

This repository contains educational material about:

- **ClawJacked** - Localhost WebSocket hijacking vulnerability
- **CVE-2026-100525** - Prometheus diagnostics scope bypass

## Structure

- `clawjacked-poc.md` - Technical writeup of the WebSocket vulnerability
- `web-poc.ts` - Demonstration script (requires OpenClaw running locally)
- `prometheus-poc.md` - Documentation of the Prometheus endpoint bypass

> All content is for educational and research purposes only.
>
> Based on public disclosures by [Oasis Security](https://www.oasis.security/) and [VulnCheck](https://www.vulncheck.com/).
