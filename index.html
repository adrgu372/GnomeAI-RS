Why GnomeAI-RS

Not another chat wrapper — a full agent with real tool use, on hardware you control.

🖥️📱

One core, two platforms

Native Linux desktop app (Avalonia) and Android client share the same Rust core. Pair them with QR or invite codes and hand sessions over safely.

🔒

Local-first & private

Conversations, drafts, attachments and API keys stay on your devices. Device sync runs through a relay you host — no third-party sync service.

🛠️

Real tool use

Shell, file edits with patches, verification, desktop control, web search, sub-agents and guarded sudo — with approvals you control.

💬

WhatsApp built in

Chat with the same agent and tools directly from WhatsApp through a local bridge. QR pairing, persistent sessions, photo support.

🧩

Skills as SKILL.md

Extend the agent with plain Markdown skill packages — install them on the desktop or directly on your phone, no build step required.

🔑

Bring your own model

OpenAI, Anthropic, Z.ai and any OpenAI-compatible endpoint — cloud or local. Pick the model per conversation.

What's new in 3.1

Built on the 3.0 Android & multi-device foundation.

  • Photos in messages — attach, render and save images on desktop and phone; shared across paired devices.
  • Mobile thinking — reasoning is persisted on the phone and shown in expandable, copyable transcript blocks.
  • On-device skills — list, inspect, install and activate SKILL.md packages straight from the Android app.
  • Model picker — per-conversation model selection on desktop and phone.
  • Handoff safety — aborted device transfers are tombstoned and can't be silently retried.
